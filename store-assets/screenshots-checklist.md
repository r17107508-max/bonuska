# Скриншоты для маркетов

В папки маркетов скопированы текущие мобильные скриншоты из `output/screenshots-tega`.

Перед публикацией лучше снять финальные скриншоты с production-данными без телефонов, токенов и ошибок.

## Клиент

1. Главный экран с QR.
2. Мои карты.
3. Партнёры.
4. Прогресс до подарка.
5. Открытие подарка.

## Компания

1. Кабинет компании.
2. Настройка программы лояльности.
3. Сканер кассира.
4. История клиентов.
5. Статистика.

## Требования к данным

- без реальных телефонов клиентов;
- без test/debug-ошибок;
- без видимых QR-токенов в сыром виде;
- с красивыми демо-компаниями;
- с понятным прогрессом до подарка.
